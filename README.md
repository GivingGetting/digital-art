## Etsy 店铺基础设置

### 1. 创建 Etsy 账户
- 访问 [Etsy.com](https://www.etsy.com)
- 点击"开店" (Sell on Etsy)
- 填写基本信息：店铺名称、语言、货币等

### 2. 店铺信息设置
- **店铺名称**：选择独特且易记的名称
- **店铺简介**：介绍你的品牌和产品
- **店铺横幅**：上传吸引人的横幅图片
- **店铺图标**：设计专业的店铺标志

### 3. 支付和税务设置
- 设置支付方式（PayPal、信用卡等）
- 填写税务信息
- 设置银行账户用于收款

### 4. 店铺政策

#### 退货政策
POD（按需打印）产品通常不接受退货，除非存在以下情况：
- 产品有质量问题（印刷错误、损坏、颜色严重偏差等）
- 收到错误的产品
- 产品与描述严重不符

**政策模板**：
> 由于我们的产品是按需打印的定制商品，除非存在质量问题，否则不接受退货或换货。如果您收到的产品有任何质量问题，请在收到后 7 天内联系我们，我们会为您免费重新制作或全额退款。

#### 隐私政策
说明如何收集、使用和保护客户数据。

**政策要点**：
- 收集的信息类型（姓名、地址、邮箱等）
- 信息用途（订单处理、客户服务等）
- 信息保护措施
- 是否与第三方共享（POD 平台、支付处理商等）
- 客户权利（访问、修改、删除数据）

**政策模板**：
> 我们重视您的隐私。我们收集的信息仅用于处理订单和提供客户服务。您的信息会与我们的 POD 合作伙伴（如 Printful）共享以完成订单，但不会出售给第三方。您可以随时联系我们查看或删除您的个人信息。

#### 运输政策
详细说明配送时间、方式和费用。

**政策要点**：
- **生产时间**：POD 产品通常需要 5-7 个工作日制作
- **配送时间**：根据目的地不同，通常 7-21 个工作日
- **配送方式**：标准配送、加急配送（如提供）
- **配送费用**：免费配送或按地区收费
- **国际配送**：说明是否支持国际配送及关税责任

**政策模板**：
> **生产时间**：5-7 个工作日
> 
> **配送时间**：
> - 美国境内：7-14 个工作日
> - 国际配送：14-21 个工作日（可能因海关延误）
> 
> **配送费用**：
> - 美国境内：免费标准配送
> - 国际配送：根据目的地计算，买家负责关税
> 
> 订单确认后，您将收到包含追踪信息的邮件。如有任何配送问题，请及时联系我们。

#### 其他政策
- **取消政策**：订单确认后 24 小时内可取消，之后进入生产流程无法取消
- **定制政策**：说明是否接受定制请求
- **批量订单**：说明是否接受批量订单及折扣政策

## Digital Art POD 商品上架

### 1. 选择 POD 平台
推荐的 POD 平台：
- **Printful**：与 Etsy 集成良好
- **Printify**：价格竞争力强
- **Gooten**：产品种类多
- **Redbubble**：适合艺术设计

### 2. 产品准备
- **设计文件**：高分辨率 PNG/PDF（至少 300 DPI）
- **产品图片**：使用 POD 平台的模拟器创建产品图
- **产品描述**：详细描述设计理念、尺寸、材质等
- **标签**：使用相关关键词（digital art, wall art, print on demand 等）

### 3. 上架步骤
1. 在 POD 平台创建产品
2. 同步到 Etsy（如果平台支持）
3. 或手动在 Etsy 创建 listing
4. 设置价格（成本 + 利润）
5. 添加产品图片和描述
6. 设置运输选项

### 4. 定价策略
- POD 成本：$10-30（取决于产品）
- Etsy 费用：$0.20 listing 费 + 6.5% 交易费
- 建议利润率：50-100%
- 最终价格 = (POD 成本 + Etsy 费用) × (1 + 利润率)

## 店铺优化建议

### SEO 优化
- **标题**：包含关键词（如 "Digital Art Print", "Wall Art", "Home Decor"）
- **标签**：使用所有 13 个标签位置
- **描述**：详细且包含关键词
- **分类**：选择正确的产品分类

### 图片优化
- 使用高质量产品图
- 展示不同使用场景
- 包含尺寸对比图
- 使用生活方式图片

### 客户服务
- 快速回复消息（24小时内）
- 提供清晰的产品信息
- 处理订单及时
- 收集客户评价

- Canva：创建设计模板

### 分析工具
- Etsy Stats：店铺数据分析
- Google Analytics：网站流量分析

## 注意事项

1. **版权**：确保所有设计都是原创或已获得授权
2. **质量**：选择可靠的 POD 供应商
3. **客户沟通**：及时回复客户询问
4. **库存管理**：POD 无需库存，但需监控供应商库存
5. **税务合规**：了解当地税务要求

## 🌐 着陆页部署

这个项目包含一个专业的着陆页（`index.html`），你可以快速部署到 GitHub Pages。

### 快速部署到 GitHub Pages

1. **创建 GitHub 仓库**
   - 登录 GitHub，创建新的 Public 仓库
   - 仓库名建议：`etsy-landing-page`

2. **上传文件**
   - 上传 `index.html` 到仓库根目录
   - 或者使用 Git：
     ```bash
     git init
     git add index.html
     git commit -m "Add landing page"
     git remote add origin https://github.com/YOUR_USERNAME/etsy-landing-page.git
     git push -u origin main
     ```

3. **启用 GitHub Pages**
   - 进入仓库 Settings → Pages
   - Source 选择 "Deploy from a branch"
   - Branch 选择 "main"，文件夹选择 "/ (root)"
   - 保存后几分钟即可访问：`https://YOUR_USERNAME.github.io/etsy-landing-page/`

📖 详细部署说明请查看 [部署指南.md](./部署指南.md)
